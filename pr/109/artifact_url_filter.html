alfresco.platform.artifact_url filter – Build the download URL of a Maven artifact on the archive or Cloudsmith server

Note

This filter plugin is part of the alfresco.platform collection (version 0.8.1).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install alfresco.platform.

To use it in a playbook, specify: alfresco.platform.artifact_url.

New in alfresco.platform 0.8.0

  • Synopsis

  • Input

  • Keyword parameters

  • Examples

  • Return Value

Synopsis

  • Builds the download and checksum URLs of a Maven artifact, picking the server with the artifact_server filter logic.

  • A version with a pre-release suffix (for example 7.4.0-RC1) uses the staging repository, any other the release one.

  • The suffix starts at -, unless the component sets prerelease_separator to None in its metadata because it has no pre-releases and uses - for release build numbers (transformers_pdf 1.3.0-86).

  • -SNAPSHOT versions are rejected, since their file names are timestamped and need maven-metadata.xml to resolve.

  • Returns the selected server too, so the caller can pick matching credentials.

  • For components that ship their Maven coordinates and repositories (for example aps_app and aps_admin), the component name is enough. Any option passed overrides the shipped value, for example repos to use a mirror.

Input

This describes the input of the filter, the value before | alfresco.platform.artifact_url.

Parameter

Comments

Input

string / required

Artifact version, for example 7.3.0 or 7.4.0-RC1.

Keyword parameters

This describes keyword parameters of the filter. These are the values key1=value1, key2=value2 and so on in the following example: input | alfresco.platform.artifact_url(key1=value1, key2=value2, ...)

Parameter

Comments

artifact_id

string

Maven artifact ID, for example activiti-app. Defaults to the component’s shipped value.

component

any / required

Component name from plugins/plugin_utils/components.py, or an explicit list of last archive versions as in the artifact_server filter.

With a list, or a component that doesn’t ship them, repos, group_id and artifact_id are required.

ext

string

File extension. Defaults to the component’s shipped value, or jar.

group_id

string

Maven group ID, for example com.activiti. Defaults to the component’s shipped value.

repos

dictionary

Base repository URLs, keyed by server and then maturity. Defaults to the component’s shipped repositories.

Structure: {"archive": {"release": url, "staging": url}, "cloudsmith": {"release": url, "staging": url}}.

Examples

- name: Download the APS war from the server that hosts the requested version
  vars:
    aps_artifact: "{{ aps_version | alfresco.platform.artifact_url('aps_app') }}"
  ansible.builtin.get_url:
    url: "{{ aps_artifact.url }}"
    checksum: "sha1:{{ aps_artifact.checksum_url }}"
    dest: /tmp/activiti-app.war
    url_username: "{{ credentials[aps_artifact.server].username }}"
    url_password: "{{ credentials[aps_artifact.server].password }}"

- name: Build the URL of an artifact the collection doesn't describe
  ansible.builtin.set_fact:
    my_artifact: >-
      {{ my_version | alfresco.platform.artifact_url(['1.4.2'], repos=my_repos,
         group_id='org.example', artifact_id='my-app', ext='zip') }}

Return Value

Key

Description

Return value

dictionary

Artifact descriptor.

Returned: success

checksum_url

string

SHA-1 checksum URL of the artifact.

Returned: success

Sample: "https://artifacts.alfresco.com/nexus/repository/activiti-enterprise-releases/com/activiti/activiti-app/24.4.1/activiti-app-24.4.1.war.sha1"

maturity

string

Repository maturity, release or staging.

Returned: success

Sample: "release"

repo_url

string

Base repository URL, without trailing slash.

Returned: success

Sample: "https://artifacts.alfresco.com/nexus/repository/activiti-enterprise-releases"

server

string

Server hosting the artifact, archive or cloudsmith.

Returned: success

Sample: "archive"

url

string

Artifact download URL.

Returned: success

Sample: "https://artifacts.alfresco.com/nexus/repository/activiti-enterprise-releases/com/activiti/activiti-app/24.4.1/activiti-app-24.4.1.war"
