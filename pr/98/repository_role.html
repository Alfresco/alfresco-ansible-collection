alfresco.platform.repository role

Note

This role is part of the alfresco.platform collection (version 0.6.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it use: ansible-galaxy collection install alfresco.platform.

To use it in a playbook, specify: alfresco.platform.repository.

Entry point kerberos – Kerberos authentication entrypoint for the repository role

Synopsis

  • Configures an already installed Alfresco Content Services repository to authenticate users with Kerberos (SPNEGO SSO). It writes the Kerberos client configuration, installs the keytab, writes the JAAS login configuration and the Kerberos authentication subsystem properties, and sets the repository authentication chain. The JVM running the repository must be started with the options exposed in the repository_kerberos_java_opts fact. It does not provision any KDC or Active Directory resources.

Parameters

Parameter

Comments

repository_authentication_chain

list / elements=string

Ordered authentication chain, as <instance>:<type> entries. It must contain the Kerberos instance. To synchronize users from Active Directory, add the instance configured by the ldap_sync entrypoint (for example ldap1:ldap-ad) before alfrescoNtlm1:alfrescoNtlm.

Default: ["{{ repository_kerberos_instance_name }}:kerberos", "alfrescoNtlm1:alfrescoNtlm"]

repository_classpath_dir

string

Repository classpath directory holding alfresco-global.properties and the alfresco/extension tree.

Default: "{{ repository_settings_dir }}/classpath"

repository_group

string

Group owning the repository configuration files.

Default: "alfresco"

repository_kerberos_admin_server

string

Kerberos admin server. Omitted from krb5.conf when empty.

Default: ""

repository_kerberos_default_administrator_usernames

list / elements=string

Users granted administrator rights by the Kerberos subsystem.

Default: []

repository_kerberos_domains

list / elements=string

DNS domains mapped to the realm in the [domain_realm] section.

Default: ["{{ repository_kerberos_realm | lower }}", ".{{ repository_kerberos_realm | lower }}"]

repository_kerberos_enctypes

list / elements=string

Encryption types allowed for tickets.

Default: ["aes256-cts-hmac-sha1-96", "aes128-cts-hmac-sha1-96"]

repository_kerberos_instance_name

string

Name of the Kerberos authentication subsystem instance.

Default: "kerberos1"

repository_kerberos_jaas_config_path

string

Path of the JAAS login configuration file on the target host.

Default: "{{ repository_settings_dir }}/java.login.config"

repository_kerberos_kdcs

list / elements=string / required

Kerberos KDC hosts, optionally with a port (for example kdc.example.com:88).

repository_kerberos_keytab_path

string

Path of the keytab on the target host.

Default: "{{ repository_settings_dir }}/alfresco.keytab"

repository_kerberos_keytab_src

string

Path of the keytab on the Ansible controller. When empty, the keytab must already exist on the target host at repository_kerberos_keytab_path.

repository_kerberos_krb5_conf_path

string

Path of the Kerberos client configuration file on the target host.

Default: "/etc/krb5.conf"

repository_kerberos_principal

string / required

Service principal held in the keytab, in the form HTTP/<host>.<domain>. The host must be the name users browse to (the load balancer name when the repository is behind a proxy).

repository_kerberos_realm

string / required

Kerberos realm, usually the DNS domain in uppercase (for example EXAMPLE.COM).

repository_kerberos_sso_enabled

repository_kerberos_sso_fallback_enabled

Fall back to another authentication mechanism when SSO fails.

Choices:

  • false

  • true ← (default)

repository_kerberos_strip_username_suffix

boolean

Strip the @domain suffix from Kerberos authenticated usernames.

Choices:

  • false

  • true ← (default)

repository_settings_dir

string

Repository settings directory on the target host.

Default: "/etc/opt/alfresco/content-services"

repository_username

User owning the repository configuration files.

Default: "alfresco"

Entry point ldap_sync – LDAP-AD user synchronization entrypoint for the repository role

Synopsis

  • Configures an LDAP-AD authentication subsystem instance used only to synchronize users and groups from Active Directory. LDAP authentication is disabled on that instance and the authentication chain is left untouched: the instance must be added to the chain by the kerberos entrypoint (or by other means) for the synchronization to run. It does not provision any Active Directory resources.
