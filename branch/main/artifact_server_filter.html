alfresco.platform.artifact_server filter – Pick the archive (Nexus) or Cloudsmith server for an artifact version

Note

This filter plugin is part of the alfresco.platform collection (version 0.8.1).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install alfresco.platform.

To use it in a playbook, specify: alfresco.platform.artifact_server.

New in alfresco.platform 0.8.0

  • Input

  • Keyword parameters

Synopsis

  • Returns archive when the version is at or below the last archive version of its major version, cloudsmith otherwise.

  • The collection ships the last archive versions of each Alfresco component, selected by name.

  • A major version with no bound, or no bounds at all, returns cloudsmith.

  • A pre-release precedes the GA version of the same base, so 7.3.9-RC1 is at or below a 7.3.9 bound and 26.3.0 is above a 26.3.0-M1 one.

  • Components whose metadata sets prerelease_separator to None, such as transformers_pdf, compare the whole version, since 1.3.0-86 is a build number.

  • Fails when a bound can’t be compared with the version, instead of silently returning cloudsmith.

Input

This describes the input of the filter, the value before | alfresco.platform.artifact_server.

Parameter

Comments

Input

string / required

Artifact version, for example 7.3.0 or 7.4.0-RC1.

Keyword parameters

This describes keyword parameters of the filter plugin. These are the values key1=value1, key2=value2 and so on in the following example: input | alfresco.platform.artifact_server(key1=value1, key2=value2, ...)

Parameter

Comments

component

any / required

Component name, for example repository, search_enterprise or aps_app. Its last archive versions come from plugins/plugin_utils/components.py. An unknown name fails.

Can also be an explicit list of last archive versions, one per major version, for example ['7.3.9', '23.4.2'].

Examples

- name: Pick the server hosting the requested version
  ansible.builtin.set_fact:
    artifact_server: "{{ acs_version | alfresco.platform.artifact_server('repository') }}"
  # 7.4.2.6, 23.7.3 -> archive
  # 7.4.3, 23.8.0   -> cloudsmith

- name: Pick the server with explicit bounds
  ansible.builtin.set_fact:
    artifact_server: "{{ my_version | alfresco.platform.artifact_server(['7.3.9', '23.4.2']) }}"

Return Value

Key

Description

Return value

string

Server hosting the artifact, archive or cloudsmith.

Returned: success

Sample: "archive"
